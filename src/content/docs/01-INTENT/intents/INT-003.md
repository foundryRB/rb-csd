---

## 1. Rationale

Correlation IDs enable:

- Request tracing across distributed systems
- Log correlation for debugging
- Performance monitoring and alerting
- Incident investigation

Every API response must include the correlation ID so clients can:

- Report issues with context
- Correlate client-side and server-side logs
- Track request flows

## 3. Examples

### 3.1 Pass Cases

| Scenario | Expected Result |
|----------|-----------------|
| Request without correlation ID | Response generates and includes new UUID |
| Request with correlation ID | Response echoes same correlation ID |
| 200 OK response | Includes X-Correlation-ID |
| 500 Error response | Includes X-Correlation-ID |

### 3.2 Fail Cases

| Scenario | Why It Fails |
|----------|--------------|
| Response missing header | Contract violation |
| Header present but empty | Contract violation |
| Different ID than request | Contract violation (should preserve) |
