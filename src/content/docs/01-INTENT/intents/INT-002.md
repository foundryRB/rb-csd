## Intent Specification

```yaml
INT-002:
  version: 1.0.0
  status: active
  statement: "Passwords must be hashed using bcrypt with cost factor >= 12"
  test:
    scope: unit
    component: PasswordService
    type: invariant
  criticality: critical
  domain: security
```

---

## 1. Rationale

Password storage security is critical for user protection. Bcrypt with cost factor 12 or higher ensures:

- Computational resistance to brute-force attacks
- Protection against rainbow table attacks
- Adequate security margin for current hardware

This invariant must hold regardless of:

- User type (admin, regular, service account)
- Password complexity
- System configuration

## 3. Examples

### 3.1 Pass Cases

| Scenario | Expected Result |
|----------|-----------------|
| Hash "password123" | Returns bcrypt hash with cost >= 12 |
| Hash empty string | Returns bcrypt hash (not error) |
| Verify correct password | Returns true |
| Verify incorrect password | Returns false |

### 3.2 Fail Cases

| Scenario | Why It Fails |
|----------|--------------|
| Hash stored as MD5 | Not bcrypt |
| Hash stored as SHA-256 | Not bcrypt (no salt, fast) |
| Bcrypt with cost 10 | Cost factor below 12 |
| Plaintext stored | No hashing at all |
